# Decathlon Sales & Customer Analysis Dashboard

**An interactive Excel dashboard created to analyse sales performance and customer behaviour for Decathlon using synthetic transaction data.**

## Dashboard Preview

[![Decathlon Sales & Customer Analysis Dashboard](dashboard-image.png)](dashboard-image.png)

## Project Overview

This project analyses 30,000 synthetic retail transactions to understand sales performance across sport categories, customer demographics, and time. It tracks how sales, orders, and customer retention shift by gender, year, and sport type, giving a full picture of business performance in a single interactive view.

## From Data to Dashboard

The project started with a structured dataset containing order details, customer demographics, product information, sales figures, and store data across 2024–2026.

Key measures — Total Sales, Total Orders, Total Customers, and Average Order Value — were built using PivotTables, and each dashboard visual is driven by a corresponding PivotChart.

## Dashboard Features

- Total Sales, Total Orders, Total Customers, and Avg Order Value KPIs
- Gender, Year, and Sport Type slicers
- Top 5 sport types by sales
- Sales trend over years (2024–2026)
- Sales breakdown by category (donut chart)
- Customer retention rate by month
- Sales breakdown by gender (donut chart)

## How to Download and Use

1. Download `decathlon-dashboard.xlsx`.
2. Open it with Microsoft Excel.
3. Go to the `DASH` worksheet.
4. Use the Gender, Year, and Sport Type slicers to explore the results.
